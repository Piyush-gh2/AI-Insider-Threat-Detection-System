# 🔐 AI Insider Threat Detection System

## 🚀 Overview
An AI-powered cybersecurity system that analyzes employee behavior, detects suspicious activities, and generates explainable risk alerts using Graph AI, RAG, and multi-agent architecture.

---

## 💡 Features
- Risk scoring engine
- Behavioral analytics
- Graph AI relationship mapping
- RAG-based threat insights
- Streamlit dashboard

---

## ▶️ Run
pip install -r requirements.txt  
streamlit run app.py
